# R25公开Agent Skill版本变更审计

本审计用于检查R24算子是否对应公开Skill仓库中真实存在的编辑形态，不用于估计
变异检出率，也不把启发式类别当成人工标注真值。仓库和主分支快照在分析前固定；
只遍历固定提交的一方主线祖先，并仅纳入既有`SKILL.md`文件的修改，不把新文件
创建或整文件删除混作维护编辑。

对每个文件修改保存仓库、提交、父提交、时间、路径、增删行数、hunk数和布尔编辑
标签，不发布第三方文件内容。`deletion_present`表示至少删除一行；
`mixed_replacement_hunk`表示同一零上下文hunk同时含增删；
`similar_line_replacement_candidate`表示混合hunk中存在规范化文本相似度至少0.55
但并不相同的增删行；`line_relocation_candidate`表示相同规范化非空行在同一提交
中既删除又新增。后两项是可复核启发式，不等价于语义参数替换或动作换序。

R24的三类算子在本审计前已冻结。审计结果无论是否支持某类形态都必须保留，且不
反向修改R24门槛、任务名单或算子定义。
