# R23独立预留集确认协议

R23只在R22全部开发门槛通过后运行。此前的暴露快照仅检查过任务ID、家族、官方
split和数量，未读取目标、轨迹、gold或结果。固定SHA-256排序从ALFWorld六个
家族各取8个valid_unseen任务，从ScienceWorld三个家族各取16个test变体，共
96个；选择不依据任务内容。

健康参考使用与开发阶段相同的原生handcoded expert/gold、环境版本和最大步数。
失败参考完整保留。随后原样复用R22的动作谓词解析器和规格生成参数，不允许根据
确认集覆盖或变异结果修改。谓词变异仍只删除匹配条件的首次动作，未覆盖任务仍为
显式推导no-op。

主终点仍是每个更新3任务预算下，相对已知技能家族后家族内随机的检出率提升。
总体门槛原样复用R22，并额外要求ALFWorld与ScienceWorld各自检出率至少0.75、
各自绝对提升至少0.15、各自条件随机化单侧p不高于0.05。任一门槛失败都不能
声称确认成功。条件随机化推断只适用于冻结的变异基准；不等价于真实生产更新总体
的统计外推。
