# PredicateImpact Submission Package

This directory contains journal-facing files that do not belong in the
anonymous reproducibility artifact. The scientific text and numerical claims
must stay synchronized with `paper/predicate_rts/en/main.tex` and the generated result
tables.

Before submission, complete `research/SUBMISSION_METADATA.md`, select the
journal and article type, then apply that journal's current template and
declaration requirements. Do not upload `title_page_template.md` with an
anonymous review manuscript unless the journal explicitly requests a separate
title page.

- `title_page_template.md`: author, affiliation, correspondence, and CRediT
  fields.
- `cover_letter_template.md`: editor-facing novelty, evidence, and declaration
  structure.
- `reviewer_response_template.md`: point-by-point revision record for later
  rounds.
- `highlights.txt`: short result-led highlights; verify the target journal's
  character limit before upload.
- `keywords.txt`: candidate indexing terms; adapt their number and spelling to
  the target journal.

The archived recovery manuscript is not the current submission. Current
scientific and administrative status is tracked in
`research/PREDICATE_RTS_SUBMISSION_READINESS.md`.

The GitHub URL, archival DOI, code/data licenses, author details, funding,
competing-interest statement, and generative-AI disclosure require author
confirmation and are intentionally not invented here.
