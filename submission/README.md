# PredicateImpact Submission Package

The finalized files prefixed with `stvr_` are prepared for initial submission
to *Software Testing, Verification and Reliability* as a Research Paper. The
scientific text and numerical claims remain synchronized with
`paper/predicate_rts/en/main.tex` and the generated result tables.

- `stvr_cover_letter.pdf`: optional editor-facing cover letter.
- `stvr_cover_letter.md`: editable text of the cover letter.
- `stvr_submission_metadata.md`: portal-ready author and declaration metadata.
- `stvr_submission_checklist.md`: final human checks and upload designations.
- `stvr_upload_manifest.csv`: files to select in the submission portal.

The generic template files below are retained for later revision rounds or a
different venue. They are not submission files and must not be uploaded.

- `title_page_template.md`: author, affiliation, correspondence, and CRediT
  fields.
- `cover_letter_template.md`: editor-facing novelty, evidence, and declaration
  structure.
- `reviewer_response_template.md`: point-by-point revision record for later
  rounds.
- `highlights.txt`: short result-led highlights; verify the target journal's
  character limit before upload.
- `keywords.txt`: candidate indexing terms; adapt their number and spelling to
  the target journal.

The archived recovery manuscript is not the current submission. Current
scientific and administrative status is tracked in
`research/PREDICATE_RTS_SUBMISSION_READINESS.md`.

The public GitHub URL, author details, funding status, competing-interest
statement, contribution statement, and generative-AI disclosure have been
confirmed. The frozen dataset is archived at
https://doi.org/10.5281/zenodo.22824889.
